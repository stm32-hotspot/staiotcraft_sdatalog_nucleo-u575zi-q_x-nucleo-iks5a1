# STEVAL-SDATALOG Serial Data Log and Inference Firmware

## Introduction

This repository contains the STAIOTCRAFT Serial Data Log and Inference firmware project for the Nucleo-U575ZIQ + IKS5A1 boards. The project is self-contained and should be opened directly from this firmware folder in Visual Studio Code.

## Features

- Serial Data Logging firmware project for NUCLEO-U575ZI-Q + IKS5A1
- Inference firmware exploiting ST Ism6hg256x sensor Machine Learnig Core
- Self-contained CMake project with Debug and Release presets
- VS Code configuration for configure, build, and debug
- ST-LINK debug workflow through Cortex-Debug

## Repository Content

Main folders in this repository:
- `.vscode` for local VS Code workspace configuration
- `Addons`, `Core`, `Drivers`, `Middlewares` firmware source code for BSP, drivers and middlewares
- `VDATALOG` firmware source for data logging FSM and MLC inference
- `X-CUBE-MEMS1` firmware source code for sensor application
- `cmake` for toolchain and generated CMake support files

## Getting Started

### Prerequisites

Install the following tools:
- STM32CubeCLT with CMake, Ninja, and GNU Arm Embedded toolchain
- Visual Studio Code
- VS Code extensions: CMake Tools, Cortex-Debug, C/C++
- ST-LINK drivers and tools for debug or flashing

### Open The Project

Open this repository folder in VS Code:
- `STAIOTCRAFT_SDATALOG_NUCLEO-U575ZI-Q_X-NUCLEO-IKS5A1`

Important:
- This project contains its own `.vscode/settings.json`.
- `cmake.sourceDirectory` is set to `${workspaceFolder}`, so this firmware folder must be opened directly.

### Configure

From this repository root:

```powershell
cmake --preset Debug
```

Additional configurations with optimizations for ReleaseSize and ReleaseSpeed are also present.

### Build

From this repository root:

```powershell
cmake --build --preset Debug
```

Additional build with optimizations for ReleaseSize and ReleaseSpeed are also present.

Recommended VS Code flow:
1. Open this repository in VS Code.
2. Let CMake Tools detect the project.
3. Use preset `Debug`.
4. Run `CMake: Configure`.
5. Run `CMake: Build`.

## Debug

1. Connect the NUCLEO-U575ZI-Q board through ST-LINK
2. Build the Debug configuration.
3. Open Run and Debug in VS Code.
4. Select a Cortex-Debug launch configuration.
5. Start the debug session.

Expected debug executable:
- `build/Debug/STAIOTCRAFT_SDATALOG_NUCLEO-U575ZI-Q_X-NUCLEO-IKS5A1.elf`

## Output

Typical output files:
- `.elf` debug image
- `.map` linker map file
- `.bin` binary image when generated by the project

Build output directory:
- `build/Debug`
- `build/ReleaseSize`
- `build/ReleaseSpeed`

## Troubleshooting

- If CMake is not found, update `.vscode/settings.json` with the correct `cmake.cmakePath`.
- If the executable is missing, configure and build the project first.
- If ST-LINK is not detected, verify USB connection, board power, and installed drivers.
